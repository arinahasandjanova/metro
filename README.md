# 🚇 Проект симуляции метро

Добро пожаловать в **Проект симуляции метро**! Это C++ приложение, которое моделирует работу метрополитена, включая движение поездов 🚆, управление станциями 🚉 и синхронизацию времени ⏰. Проект использует многопоточность (pthreads) и современные возможности C++20 для создания реалистичной симуляции.

---

## 📖 Обзор проекта

Проект предназначен для:
- **Симуляции работы метро**: Поезда движутся между станциями по расписанию.
- **Изучения многопоточности**: Использует POSIX Threads для параллельного выполнения.
- **Практики C++20**: Применяет современные стандарты C++ для объектно-ориентированного программирования.
- **Визуализации процессов**: Выводит в консоль события, такие как отправления и прибытия поездов.

Это отличный инструмент для студентов и разработчиков, которые хотят разобраться в многопоточности, синхронизации и системном моделировании.

---

## 🗂 Структура проекта

Проект состоит из следующих файлов, каждый из которых выполняет свою роль:

- **📄 `main.cpp`**: Точка входа, запускает симуляцию и управляет потоками.
- **📄 `station.cpp` / `station.hpp`**: Реализует класс `Station` для управления станциями.
- **📄 `train.cpp` / `train.hpp`**: Определяет класс `Train` для моделирования поездов.
- **📄 `clock.cpp` / `clock.hpp`**: Реализует класс `Clock` для синхронизации времени.
- **📄 `all_stations.cpp` / `all_stations.hpp`**: Управляет сетью станций.
- **📄 `.gitignore`**: Исключает временные файлы (например, бинарные) из Git.
- **📄 `README.md`**: Этот документ с инструкциями.

## 📦 Установка

Следуйте этим шагам, чтобы настроить проект:

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/arinahasandjanova/metro.git
   cd metro
   ```

2. **Проверьте версию `g++`**:
   ```bash
   g++ --version
   ```
   Если версия < 10, обновите:
   ```bash
   sudo apt-get update
   sudo apt-get install g++-10
   ```

3. **Убедитесь, что `pthread` доступен**:
   На Linux это часть `g++`. Установите инструменты, если нужно:
   ```bash
   sudo apt-get install build-essential
   ```

---

## 🔨 Компиляция

Скомпилируйте проект с помощью следующей команды:

```bash
g++ -std=c++20 -pthread -I. main.cpp station.cpp train.cpp clock.cpp all_stations.cpp -o metro
```

### Флаги компиляции
- `-std=c++20`: Активирует стандарт C++20.
- `-pthread`: Подключает библиотеку потоков.
- `-I.`: Указывает текущую директорию для заголовков.
- `-o metro`: Имя выходного файла — `metro`.

### Возможные ошибки
- **"`pthread_create` не определено"**: Добавьте флаг `-pthread`.
- **"C++20 не поддерживается"**: Обновите `g++`.
- **"Заголовок не найден"**: Проверьте наличие всех `.hpp` файлов.
