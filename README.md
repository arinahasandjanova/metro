# 🚇 Проект симуляции метро

Добро пожаловать в **Проект симуляции метро**! Это C++ приложение, которое моделирует работу метрополитена, включая движение поездов 🚆, управление станциями 🚉 и синхронизацию времени ⏰. Проект использует многопоточность (pthreads) и современные возможности C++20 для создания реалистичной симуляции.

---

## 📖 Обзор проекта

Проект предназначен для:
- **Симуляции работы метро**: Поезда движутся между станциями по расписанию.
- **Изучения многопоточности**: Использует Threads для параллельного выполнения.
- **Практики C++20**: Применяет современные стандарты C++ для объектно-ориентированного программирования.
- **Визуализации процессов**: Выводит в консоль события, такие как отправления и прибытия поездов.

Это отличный инструмент для студентов и разработчиков, которые хотят разобраться в многопоточности, синхронизации и системном моделировании.

---

## 🗂 Структура проекта

Проект состоит из следующих файлов, каждый из которых выполняет свою роль:

- **📄 `metro.h`**: Хедер файл для всех кдассов и функций.
- **📄 `main.cpp`**: Точка входа, запускает симуляцию и управляет потоками.
- **📄 `station.cpp`**: Реализует класс `Station` для управления станциями.
- **📄 `train.cpp`**: Определяет класс `Train` для моделирования поездов.
- **📄 `clock.cpp`**: Реализует класс `Clock` для синхронизации времени.
- **📄 `all_stations.cpp`**: Управляет сетью станций.
- **📄 `README.md`**: Этот документ с инструкциями.

## 📦 Установка

Следуйте этим шагам, чтобы настроить проект:

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/arinahasandjanova/metro.git
   cd metro
   ```

2. **Скомпилируйте проект с помощью следующей команды**:

```bash
g++ -std=c++20 -pthread -I. main.cpp station.cpp train.cpp clock.cpp all_stations.cpp -o metro
```
3. **После компиляции запустите программу**:

```bash
./metro
```
4. **Зайдите в созданный файлы с помощью программы через которую можно просматривать маркдаун файлы**

### Что вы увидите в терминале
- **Инициализация**: Создание станций и поездов.
- **Завершение**: Итоговое сообщение о завершении.
---

### Что вы увидите в файлах
- **Обновления в реальном времени**:
  - «Поезд 1 отправился со станции А на станцию Б».
  - Текущее время симуляции.
  - id поезда.

## 🌟 Особенности проекта

- **Многопоточность** 🧵: Pthreads обеспечивают параллельное движение поездов.
- **Объектно-ориентированный подход** 🏗: Классы `Station`, `Train`, `Clock` упрощают поддержку кода.
- **Синхронизация времени** ⏳: `Clock` координирует действия потоков.
- **Модульность** 📦: Код разделен на логические модули для удобства.
